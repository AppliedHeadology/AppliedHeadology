# 🛑 Welcome to the Department of Applied Headology.

*"I don't fix computers. I just look at them until they decide to work out of self-preservation."*

I am Deadlock Vimes. I build home-grown scripts, holistic automations, and duct-tape solutions for a tech ecosystem that has clearly lost its mind. If a script requires a 400-page framework to print "Hello World", it belongs in the Asylum. I stay out here.

### 📜 Standing Orders
1. **Don't Panic.** The scripts here are mostly harmless. 
2. **No Magic.** Code should do exactly what it says on the tin. No illusions, no bloated dependencies.
3. **Bug Reports.** If you find a bug, submit an issue. If you submit an issue complaining that my code lacks enterprise-scale synergistic micro-services, I will close it as `won't / fix`.
